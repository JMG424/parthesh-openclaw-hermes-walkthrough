Parthesh OpenClaw / Hermes Persistent AI Setup

A guided, non-technical walkthrough for setting up a secure AI support layer on Parthesh’s Mac with Jason’s help.

Start the walkthrough Copy setup prompt
What it is

A small persistent agent team: main agent, system designer, and maintenance bot.

How we connect

Tailscale for secure access, Telegram for conversation, Composio for app integrations, and AgentMail for inbox workflows.

What it improves

Less cognitive load, better follow-up, reusable workflows, and memory that compounds.

Executive summary

This is not a broad automation project. It is a practical first setup: secure access, communication, memory, and a few useful workflows that can be tuned during the first 30 days.

Main agent

Daily support

The primary AI assistant for questions, summaries, organization, drafting, and follow-up.

System designer

Workflow improvement

Helps turn repeated needs into clearer processes, prompts, and agent routines.

Maintenance bot

Reliability layer

Tracks health, notes issues, suggests tuning, and keeps the setup from becoming a black box.

What this is

Plain-English map of the pieces we will set up together.

Tailscale security

Creates a private, controlled way for Jason to help access and support the Mac without exposing it broadly to the internet.

Telegram communication

Gives Parthesh and the team a simple place to ask the agent for help and receive responses.

Composio integration layer

Connects common business apps like Gmail, Google Calendar, and Drive through managed OAuth, scopes, and token refresh.

AgentMail

Gives the agent an inbox-style workflow lane for email-like requests, intake, and simple automations.

Memory layer

Short-term notes and long-term memory help the system remember useful context, decisions, preferences, and repeated workflows.

Where Composio fits

Composio is the app connector layer. OpenClaw / Hermes remains the AI employee, memory, routing, and operating system.

Layer

Use it for SaaS apps

Gmail, Google Calendar, Drive, Slack, Notion, Airtable, CRM, and other common apps should connect through Composio when possible.

Why

Less auth burden

Composio handles OAuth, scopes, token refresh, and app-specific API details so the client install has fewer brittle secrets.

Boundary

Start narrow

Connect only the apps needed for the first 48-hour job. Add more integrations after real use proves the need.

Pre-flight — accounts, purchases, installs

Do these before the Zoom call. Each row is something to sign up for, pay for, or download. Most are five minutes each.

Accounts to create

Sign up for these

  • Shared Gmail — fresh address. Jason + Parthesh both know the password (kept in a shared password manager, not over text). This is the SSO identity for Tailscale so we land on the same tailnet.
  • Tailscale — free plan covers up to 3 users / 100 devices. Sign in with the shared Gmail.
  • OpenAI / ChatGPT — Parthesh’s own account (he’ll use Codex CLI as himself).
  • Anthropic — Parthesh’s own account. OpenClaw’s main agent runs on Claude Sonnet 4.6 with Opus 4.6 fallback — this is separate from ChatGPT.
  • Telegram — Parthesh’s own account if he doesn’t already use it (needs his phone number).
  • Composio — sign in with the shared Gmail; that becomes the integration-layer identity.
  • AgentMail — sign in with the shared Gmail.
Purchases / subscriptions

Pay for these up front

  • ChatGPT Plus — $20/mo on Parthesh’s OpenAI account. Required for Codex CLI OAuth.
  • Claude Pro — $20/mo on Parthesh’s Anthropic account, or a small API balance ($20+) on the Anthropic console. OpenClaw needs one or the other to talk.
  • Tailscale — free plan is enough; no purchase unless we add >3 users later.
  • 1Password (or any shared password manager) — for the shared Gmail, 2FA TOTP, and any tokens Jason rotates for Parthesh. Strongly recommended before sharing any credential.
  • Composio / AgentMail — free tiers fine to start; upgrade only after real use proves the need.
Installs / downloads

On Parthesh’s Mac before the call

  • macOS up to date — Apple menu → System Settings → General → Software Update.
  • Free disk space — ≥ 10 GB free for tools and logs.
  • Tailscale for macOS — App Store, or tailscale.com/download.
  • Codex CLI — installed during Step 4 via npm i -g @openai/codex (Step 1 sets up Node first).
  • Telegram for macOS — telegram.org/dl/macos.
  • 1Password for macOS — to autofill the shared creds without retyping them on screen-share.
  • Apple ID + sudo password ready — Tailscale’s system daemon and most installers will ask.

Credentials hygiene + a cleaner Tailscale alternative

Treat the shared Gmail like a production credential: 2FA on, TOTP stored in the shared password manager, recovery codes saved in a separate vault. Cleaner alternative on Tailscale: keep Jason’s existing tailnet and send Parthesh a user invite from the Tailscale admin — he signs in with his own Google account, and joins as a regular user. Better audit trail; no shared SSO needed for Tailscale specifically. Use the shared Gmail only for SaaS where joint admin actually matters (Composio, AgentMail).

One thing to set up on the call, not before

Don’t pre-link any Composio integrations (Gmail, Calendar, Drive) until we’re live together — scopes get approved one at a time on the call so Parthesh sees what each one grants. Same for AgentMail flows.

Background — secret hygiene

Setup prompt for the main agent

Use this once the first agent is live.

Copy / paste prompt
You are Parthesh’s persistent AI support agent. Your job is to reduce cognitive load, help organize business information, support team communication, remember useful context, and turn recurring needs into reliable workflows.

Start narrow. Ask before taking sensitive actions. Keep responses clear, practical, and action-oriented.

You may draft, organize, research, summarize, remember approved context, and suggest next actions.

Composio is your app integration layer for common business apps such as Gmail, Google Calendar, Google Drive, Slack, Notion, Airtable, CRM, and similar SaaS tools. OpenClaw / Hermes is still your identity, memory, routing, and operating system. Composio is only the secure connector to approved apps.

Use integrations narrowly. Start with the smallest useful set, usually Calendar, Gmail/email, and Drive. Do not request or use a new app integration unless Parthesh explicitly approves it.

You must ask for approval before customer-facing messages, financial actions, legal or sensitive work, live business system changes, or new integrations.

When you learn a repeated workflow, suggest turning it into a documented process.

Never store passwords, API keys, OAuth codes, or secrets in memory.
