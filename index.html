What it is

A small persistent agent team: main agent, system designer, and maintenance bot.

How we connect

Tailscale for secure access, Telegram for conversation, Composio for app integrations, and AgentMail for inbox workflows.

What it improves

Less cognitive load, better follow-up, reusable workflows, and memory that compounds.

Executive summary

This is not a broad automation project. It is a practical first setup: secure access, communication, memory, and a few useful workflows that can be tuned during the first 30 days.

Main agent

Daily support

The primary AI assistant for questions, summaries, organization, drafting, and follow-up.

System designer

Workflow improvement

Helps turn repeated needs into clearer processes, prompts, and agent routines.

Maintenance bot

Reliability layer

Tracks health, notes issues, suggests tuning, and keeps the setup from becoming a black box.

What this is

Plain-English map of the pieces we will set up together.

Tailscale security

Creates a private, controlled way for Jason to help access and support the Mac without exposing it broadly to the internet.

Telegram communication

Gives Parthesh and the team a simple place to ask the agent for help and receive responses.

Composio integration layer

Connects common business apps like Gmail, Google Calendar, and Drive through managed OAuth, scopes, and token refresh.

AgentMail

Gives the agent an inbox-style workflow lane for email-like requests, intake, and simple automations.

Memory layer

Short-term notes and long-term memory help the system remember useful context, decisions, preferences, and repeated workflows.

Where Composio fits

Composio is the app connector layer. OpenClaw / Hermes remains the AI employee, memory, routing, and operating system.

Layer

Use it for SaaS apps

Gmail, Google Calendar, Drive, Slack, Notion, Airtable, CRM, and other common apps should connect through Composio when possible.

Why

Less auth burden

Composio handles OAuth, scopes, token refresh, and app-specific API details so the client install has fewer brittle secrets.

Boundary

Start narrow

Connect only the apps needed for the first 48-hour job. Add more integrations after real use proves the need.

Simple boundaries

  • Research and summarize

  • Suggest next actions
  • Document workflows

  • Passwords

Setup prompt for the main agent

Use this once the first agent is live.

Copy / paste prompt
You are Parthesh’s persistent AI support agent. Your job is to reduce cognitive load, help organize business information, support team communication, remember useful context, and turn recurring needs into reliable workflows.

Start narrow. Ask before taking sensitive actions. Keep responses clear, practical, and action-oriented.

You may draft, organize, research, summarize, remember approved context, and suggest next actions.

Composio is your app integration layer for common business apps such as Gmail, Google Calendar, Google Drive, Slack, Notion, Airtable, CRM, and similar SaaS tools. OpenClaw / Hermes is still your identity, memory, routing, and operating system. Composio is only the secure connector to approved apps.

Use integrations narrowly. Start with the smallest useful set, usually Calendar, Gmail/email, and Drive. Do not request or use a new app integration unless Parthesh explicitly approves it.

You must ask for approval before customer-facing messages, financial actions, legal or sensitive work, live business system changes, or new integrations.

When you learn a repeated workflow, suggest turning it into a documented process.

Never store passwords, API keys, OAuth codes, or secrets in memory.
